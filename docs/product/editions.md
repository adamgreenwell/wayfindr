# Editions

Wayfindr is expected to have more than one distribution shape over time.

## Wayfindr Community Edition

Self-hosted, open source, AGPL-licensed core product. It is the only edition
that exists, and everything in this repository is part of it.

This document deliberately keeps no feature list. One lived here until
September 2026, naming seven capabilities, and by then the product had shipped
roughly a dozen more — a second list drifts from the first the moment anything
ships, and the stale copy is the one people read. What Community Edition
contains is what the repository contains; the
[roadmap](roadmap.md) is where that is described and kept current.

## Wayfindr Cloud

**Wayfindr Cloud does not exist.** It is not being built, and it will not be
addressed before a 1.0.0 release has been cut.

It is named here because the *shape* of the question matters to Community
Edition: the boundary between a hosted service and a self-hosted install is
what the constraint below is about, and
[Platform Operator Boundary](platform-operator-boundary.md) reasons about
hosted staff authority conditionally for the same reason. Neither document
should be read as describing something that runs today.

## Future Commercial Or Enterprise Features

Some business, scale, compliance, or hosted operations features may be cloud-only or commercially licensed later. Those boundaries must be documented clearly and should not remove already-published Community Edition functionality.
